# Foxy

the worst mayor of all time

## configuration

Use `/foxy` or `/foxy view` to see settings

- `/foxy set fruitdigging <true|false>` auto fruit digging (average ~3,500 score)
- `/foxy set zombieshootout <true|false>` auto zombie shootout (average ~10,000 score)
- `/foxy set catchafish <true|false>` auto catch a fish (average ~7,000 score)
- `/foxy set verbose <true|false>` logs action information in chat
- `/foxy set autostart <true|false>` automatically play rounds continuously

---

build with `./gradlew :<version>:build` (or
`gradlew.bat :<version>:build` on Windows)
